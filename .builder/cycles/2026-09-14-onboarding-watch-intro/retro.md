# Retro

- Belief: new users need an explicit introduction to the Apple Watch hands-free value proposition before seeing the activation card inside the Reader.
- Learning: inserting a single focused value page between publication selection and the Reader gives the core differentiator a dedicated moment without returning to the previous 3-page onboarding friction. iPad remains completely streamlined.
- Decision: close the cycle with a pass; ship in the next TestFlight build to verify real first-run activation and Watch page-turn completion.
- Follow-up: observe first-run TestFlight metrics for Watch setup completion rate vs. drop-off; loop back only if the extra step introduces drop-off or if testers report redundancy with the Reader activation card.
