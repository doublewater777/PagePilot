# Retro

- Belief: onboarding should build context first (value proposition), take the user's action second (choose a book), and immediately reward them with the result (reading in Reader).
- Learning: placing the intro page after book selection broke the natural momentum between choosing a book and opening it; introducing the Watch value proposition first makes book import the natural final step into the reader.
- Decision: close the cycle with a pass; ship in the next TestFlight build to verify real first-run activation and Watch page-turn completion.
- Follow-up: observe first-run TestFlight metrics for Watch setup completion rate vs. drop-off; loop back only if the intro step introduces drop-off or if testers report redundancy with the Reader activation card.
