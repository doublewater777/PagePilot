# Retro

- Belief: the Live Activity earns its place only while it enables Watch page turning; a backgrounded Reader cannot be paged, so the activity should end.
- Learning: the retained-session split solved a problem the product does not have; ending on background keeps the lifecycle obvious and stats sessions short and accurate.
- Decision: reverse this cycle's earlier pass; backgrounding now ends the session and foregrounding restarts it.
- Follow-up: loop back only if readers report missing the Lock Screen reading status.
