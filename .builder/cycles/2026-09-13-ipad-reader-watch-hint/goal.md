# Goal

- User problem: the first iPad Reader hint describes an old setup path and does not explain the current Watch Live Activity flow.
- Target user: iPad readers with a paired Apple Watch who are opening their first visual Reader.
- Desired behavior: the hint leads with the outcome, then explains that the Watch shows reading controls and the Live Activity opens the Watch app.
- Success: all supported localizations use the same outcome-first message and the copy regression test passes.
- Out of scope: changing trigger timing, card layout, iPhone onboarding, or Live Activity behavior.
