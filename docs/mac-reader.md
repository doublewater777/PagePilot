# Mac 阅读指南

PagePilot 的 Mac 版本使用 Mac Catalyst，书架和阅读器分别在独立窗口中呈现。本文对应已提交审核的 Mac 1.0.24（53）；仓库开发版本为 1.0.25，实际下载版本以 App Store 为准。

## 书架与窗口

- Mac 书架固定使用封面网格，可筛选全部图书、正在阅读、未读和已读完。
- 打开图书会创建独立阅读窗口，再次打开同一本书会回到已有窗口。
- 不同图书可在不同窗口中阅读，书架窗口可继续用于挑选图书。
- 右键图书可打开阅读窗口、查看书籍信息或移除图书。

## 鼠标与触控板

分页阅读 EPUB 或 PDF 时，可使用底部上一页／下一页按钮、鼠标滚轮或触控板双指滚动翻页。一次触控板手势最多翻一页，避免惯性滚动连续跳页。

连续阅读模式保留原生滚动；PDF 放大后保留原生平移，以便查看页面细节。

## 阅读快捷键

| 操作 | 快捷键 |
| --- | --- |
| 上一页／下一页 | 左／右方向键 |
| 下一页 | 空格 |
| 上一页 | Shift + 空格 |
| 目录 | Command + Shift + O |
| 书内搜索 | Command + F |
| 添加书签 | Command + D |
| 阅读设置 | Command + Shift + P |
| 关闭阅读面板 | Esc |

快捷键在对应阅读窗口中使用；输入框和系统弹窗可能接管键盘事件。

## Apple Watch 翻页

1. 在 Mac 和配对的 iPhone 上打开 PagePilot，允许本地网络访问，并连接同一 Wi-Fi。
2. 在 iPhone 的「我 → 手表翻页 → 选择附近的 iPad / Mac」中选择 Mac。
3. 在 Mac 上打开图书，再用该 iPhone 配对的 Apple Watch 翻页。

iPhone 和 Mac 均需要 Pro 权限。Watch 指令通过 iPhone 中继，Mac 不直接与 Apple Watch 配对，也不创建实时活动。

## iPhone 与 iPad

独立 Mac 窗口和固定封面网格是 Mac 专属行为。iPhone 和 iPad 保留各自的导航与书架布局；iPad 需要兼容分屏和窗口缩放。
